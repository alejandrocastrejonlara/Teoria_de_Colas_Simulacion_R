Implementación de un modelo de simulación de eventos discretos en R para optimizar los tiempos de espera y medir la utilización de servidores en una estación de servicio.

Estimación de Parámetros y Bondad de Ajuste: Ajuste de distribuciones de probabilidad (Exponencial, Weibull, Gamma) utilizando el método de máxima verosimilitud (MLE) para modelar tiempos de interarribo y servicio.   

Pruebas Estadísticas: Ejecución algorítmica de pruebas de Kolmogorov-Smirnov, Anderson-Darling y Cramer-von Mises para validar la idoneidad de las distribuciones seleccionadas.   

Simulación Monte Carlo (Teoría de Colas): Programación de un motor de simulación para modelar el flujo de clientes durante un periodo operativo (12 horas), calculando métricas clave como el tiempo promedio de espera en cola y la tasa de utilización del servidor.   

Visualización de Datos: Creación de histogramas y curvas de densidad paramétricas utilizando ggplot2 y reglas de segmentación matemática (Sturges, Scott, Freedman-Diaconis).
